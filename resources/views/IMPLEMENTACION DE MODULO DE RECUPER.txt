3️⃣ FLUJO DE PROCESO
┌─────────────────────────────────────────────────────────┐
│ GENERACIÓN DE PENALIZACIONES (Automático - Diario)     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. Validar sesiones completadas hoy                   │
│  2. Comparar con horario programado                    │
│  3. Calcular diferencia (horas faltantes)              │
│  4. Si horas_faltantes > 0:                            │
│     └─ Crear registro en "penalties"                   │
│     └─ Status = "pending"                              │
│     └─ Notificar al aprendiz                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ SOLICITUD DE RECUPERACIÓN (Aprendiz)                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. Aprendiz ve sus penalizaciones                     │
│  2. Crea solicitud para trabajar sábado/domingo        │
│  3. Especifica:                                        │
│     └─ Fecha deseada                                   │
│     └─ Horas a recuperar (no puede exceder penalty)   │
│  4. Status = "pending"                                 │
│  5. Notificación al admin                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ APROBACIÓN O RECHAZO (Admin)                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Admin Panel:                                          │
│  - Ver todas las solicitudes pendientes                │
│  - Aprobar: Status = "approved"                        │
│  - Rechazar + comentario: Status = "rejected"          │
│  - Crear sesión de recuperación                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ SESIÓN DE RECUPERACIÓN (Sábado/Domingo)               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. Se crea sesión en "recovery_sessions"              │
│  2. Aprendiz entra y registra entrada/salida           │
│  3. Sistema calcula horas trabajadas                   │
│  4. Compara con horas solicitadas                      │
│  5. Si completa:                                       │
│     └─ Penalty status = "closed"                       │
│     └─ Recovery request status = "completed"           │
│     └─ Notificar aprendiz                              │
│                                                         │
└─────────────────────────────────────────────────────────┘

7️⃣ RUTAS
<?php
// Rutas del Aprendiz
Route::middleware(['auth', 'verified', 'apprentice.only'])->prefix('apprentice')->name('apprentice.')->group(function () {
    // Penalizaciones
    Route::get('penalties', [ApprenticeP enaltyController::class, 'index'])->name('penalties.index');
    Route::get('penalties/{penalty}', [ApprenticeP enaltyController::class, 'show'])->name('penalties.show');
    Route::post('penalties/{penalty}/request-recovery', [ApprenticeP enaltyController::class, 'requestRecovery'])->name('penalties.request-recovery');
    Route::get('recovery-requests', [ApprenticeP enaltyController::class, 'recoveryRequests'])->name('recovery-requests.index');
});

// Rutas del Admin
Route::middleware(['auth', 'verified', 'admin.only'])->prefix('admin')->name('admin.')->group(function () {
    // Penalizaciones
    Route::get('penalties', [AdminPenaltyController::class, 'index'])->name('penalties.index');
    Route::post('penalties/{penalty}/approve', [AdminPenaltyController::class, 'approvePenalty'])->name('penalties.approve');
    Route::post('penalties/{penalty}/reject', [AdminPenaltyController::class, 'rejectPenalty'])->name('penalties.reject');
    
    // Solicitudes de Recuperación
    Route::get('recovery-requests', [AdminPenaltyController::class, 'recoveryRequests'])->name('recovery-requests.index');
    Route::post('recovery-requests/{request}/approve', [AdminPenaltyController::class, 'approveRecovery'])->name('recovery-requests.approve');
    Route::post('recovery-requests/{request}/reject', [AdminPenaltyController::class, 'rejectRecovery'])->name('recovery-requests.reject');
    
    // Sesiones de Recuperación
    Route::resource('recovery-sessions', RecoverySessionController::class);
    Route::post('recovery-sessions/{session}/close', [RecoverySessionController::class, 'close'])->name('recovery-sessions.close');
});

8️⃣ NOMBRE ALTERNATIVO PARA EL MÓDULO
Opción	Pros	Contras
Penalizaciones	Claro y directo	Suena negativo
Deuda de Horas	Neutral	Confuso
Recuperación	Positivo	Vago
Compensación	Profesional	Menos claro
Cumplimiento Horario	Descriptivo	Largo
Horas Pendientes	Neutral	Genérico
Crédito de Horas	Positivo	No refleja penalización
Mi recomendación: "Módulo de Recuperación de Horas" o "Gestión de Incumplimientos"
